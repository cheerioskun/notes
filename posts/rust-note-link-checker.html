A useful small Rust program

The link rot patrol.

A Markdown notebook starts clean. Then files move, drafts get renamed, images disappear, and old links keep pointing at ghosts. A tiny Rust command can walk the tree and name the damage.

§1 — The notebook lies quietly.

The worst broken links are not the ones in a public site. Those fail loudly. The private ones sit in a notes folder for months. A future version of you clicks [ownership notes](./ownership.md) and lands nowhere.

The command should do one thing:

$ mdlinks ~/repos/notes
missing: posts/rust.md -> ./ownership.md
missing: posts/tools.md -> ../images/diagram.png

No server. No database. No configuration file. Just a patrol through Markdown files, looking for local targets that no longer exist.

A good small command has a smell: it could have been a shell script, until the edge cases started breeding.

§2 — Give the command a body.

Create a project:

cargo new mdlinks
cd mdlinks

Start with the outside edge: accept a directory, default to the current one, and print what will be scanned.

use std::env;
use std::path::PathBuf;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let root = env::args()
        .nth(1)
        .map(PathBuf::from)
        .unwrap_or(env::current_dir()?);

    println!("scanning {}", root.display());
    Ok(())
}

PathBuf is the right container here because the program keeps the path. It is not merely looking at a path owned by someone else; it is taking one from the command line or constructing one from the current directory.

The return type on main keeps the first version clean. env::current_dir() can fail. The ? passes that failure upward instead of turning the first file into a nest of match blocks.

§3 — Walk the tree.

The standard library gives one directory at a time. Recursion supplies the rest.

use std::fs;
use std::path::{Path, PathBuf};

fn markdown_files(dir: &Path, out: &mut Vec<PathBuf>) -> std::io::Result<()> {
    for entry in fs::read_dir(dir)? {
        let entry = entry?;
        let path = entry.path();

        if path.is_dir() {
            markdown_files(&path, out)?;
        } else if path
            .extension()
            .is_some_and(|ext| ext == "md" || ext == "markdown")
        {
            out.push(path);
        }
    }

    Ok(())
}

The function borrows the directory path and borrows the output vector mutably. Every file path discovered by entry.path() is owned by this function. When it is a Markdown file, it gets moved into out.

Try this Skip noisy directories. Before recursing, check whether the directory name is .git or target.
One compact helper 
fn should_skip_dir(path: &Path) -> bool {
    path.file_name()
        .is_some_and(|name| name == ".git" || name == "target")
}

§4 — Do not write a Markdown parser.

Markdown is larger than it looks. This command only needs a useful slice of it: ordinary inline links shaped like [label](target). A small scanner is enough.

#[derive(Debug, PartialEq, Eq)]
struct Link {
    target: String,
}

fn links_in_line(line: &str) -> Vec<Link> {
    let mut links = Vec::new();
    let mut rest = line;

    while let Some(open_label) = rest.find('[') {
        rest = &rest[open_label + 1..];

        let Some(close_label) = rest.find("](") else { break };
        rest = &rest[close_label + 2..];

        let Some(close_target) = rest.find(')') else { break };
        let target = &rest[..close_target];
        links.push(Link { target: target.to_string() });
        rest = &rest[close_target + 1..];
    }

    links
}

rest is a window into line. It keeps sliding right. The scanner borrows while searching, then stores an owned String for the target it found.

Put a few pins in it before wiring it to the filesystem:

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn extracts_multiple_links() {
        let links = links_in_line("see [a](./a.md) and [b](../b.md)");
        assert_eq!(
            links,
            vec![
                Link { target: "./a.md".to_string() },
                Link { target: "../b.md".to_string() },
            ]
        );
    }

    #[test]
    fn ignores_plain_text() {
        assert!(links_in_line("nothing to see here").is_empty());
    }
}
Known limitation This scanner does not handle escaped brackets, reference-style links, images, or code spans. That is acceptable for a first pass. The command can be useful before it is complete.

§5 — A link is not a path until it has a source.

./draft.md means “beside the file I am in.” If the command checks every link relative to the root scan directory, it will report nonsense.

fn is_local_link(target: &str) -> bool {
    !(target.starts_with("http://")
        || target.starts_with("https://")
        || target.starts_with("mailto:")
        || target.starts_with('#'))
}

fn strip_fragment(target: &str) -> &str {
    target.split_once('#').map_or(target, |(path, _fragment)| path)
}

fn resolve_link(markdown_file: &Path, target: &str) -> Option<PathBuf> {
    if !is_local_link(target) {
        return None;
    }

    let without_fragment = strip_fragment(target);
    if without_fragment.is_empty() {
        return None;
    }

    let base_dir = markdown_file.parent()?;
    Some(base_dir.join(without_fragment))
}

Web links are somebody else’s patrol. Anchor-only links point inside the current document. Fragment suffixes such as #section-two should not be part of the filesystem check.

#[test]
fn strips_fragments_before_checking_the_file() {
    assert_eq!(strip_fragment("./post.md#section-2"), "./post.md");
}

#[test]
fn ignores_web_and_anchor_links() {
    assert!(!is_local_link("https://example.com"));
    assert!(!is_local_link("mailto:me@example.com"));
    assert!(!is_local_link("#local-heading"));
    assert!(is_local_link("./neighbor.md"));
}

§6 — The command.

Replace src/main.rs with this:

use std::env;
use std::error::Error;
use std::fs;
use std::path::{Path, PathBuf};

#[derive(Debug, PartialEq, Eq)]
struct Link {
    target: String,
}

#[derive(Debug)]
struct BrokenLink {
    source: PathBuf,
    target: String,
    resolved: PathBuf,
}

fn main() -> Result<(), Box<dyn Error>> {
    let root = env::args()
        .nth(1)
        .map(PathBuf::from)
        .unwrap_or(env::current_dir()?);

    let mut files = Vec::new();
    markdown_files(&root, &mut files)?;

    let mut broken = Vec::new();
    for file in files {
        broken.extend(broken_links_in_file(&file)?);
    }

    if broken.is_empty() {
        println!("no missing local links found under {}", root.display());
    } else {
        for item in &broken {
            println!(
                "missing: {} -> {} ({})",
                item.source.display(),
                item.target,
                item.resolved.display()
            );
        }
        std::process::exit(1);
    }

    Ok(())
}

fn markdown_files(dir: &Path, out: &mut Vec<PathBuf>) -> std::io::Result<()> {
    for entry in fs::read_dir(dir)? {
        let entry = entry?;
        let path = entry.path();

        if path.is_dir() {
            markdown_files(&path, out)?;
        } else if path
            .extension()
            .is_some_and(|ext| ext == "md" || ext == "markdown")
        {
            out.push(path);
        }
    }

    Ok(())
}

fn broken_links_in_file(file: &Path) -> std::io::Result<Vec<BrokenLink>> {
    let text = fs::read_to_string(file)?;
    let mut broken = Vec::new();

    for line in text.lines() {
        for link in links_in_line(line) {
            let Some(resolved) = resolve_link(file, &link.target) else {
                continue;
            };

            if !resolved.exists() {
                broken.push(BrokenLink {
                    source: file.to_path_buf(),
                    target: link.target,
                    resolved,
                });
            }
        }
    }

    Ok(broken)
}

fn links_in_line(line: &str) -> Vec<Link> {
    let mut links = Vec::new();
    let mut rest = line;

    while let Some(open_label) = rest.find('[') {
        rest = &rest[open_label + 1..];

        let Some(close_label) = rest.find("](") else { break };

        let Some(close_target) = rest.find(')') else { break };
        let target = &rest[..close_target];
        links.push(Link { target: target.to_string() });
        rest = &rest[close_target + 1..];
    }

    links
}

    !(target.starts_with("http://")
        || target.starts_with("https://")
        || target.starts_with("mailto:")

Run the pins first:

cargo test

Then point it at a folder with Markdown in it:

cargo run -- ~/repos/notes

The program exits with status code 1 when it finds broken links. That makes it usable in scripts later: silence means clean, failure means investigate.

§7 — Small improvements worth making.

Add line numbers

Change the scan loop to keep the line index:

for (index, line) in text.lines().enumerate() {
    let line_number = index + 1;
    // store line_number in BrokenLink
}

A report that says posts/rust.md:42 is much nicer than one that merely names the file.

Group output by file

A flat list gets noisy. Grouping by source file makes repair work faster. Reach for a HashMap<PathBuf, Vec<BrokenLink>> when the report starts feeling like a ledger.

Ignore code blocks

Markdown examples often contain fake links. Track whether the scanner is between triple backticks and skip those lines. That adds one boolean and removes a whole class of false positives.

Decide whether images count

The current scanner sees ![alt](image.png) as a link too. That may be exactly what you want. If not, check whether the character before [ is !.

The next version The program is ready to become a real personal tool when it reports line numbers, skips .git and target, and ignores fenced code blocks. After that, the larger jump is replacing the tiny scanner with a Markdown parser crate.
